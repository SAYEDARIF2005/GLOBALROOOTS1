# GLOBALROOOTS1 — Premium Export & Trade Web Platform

![GLOBALROOOTS1 Banner](assets/global_trade_side.jpg)

**GLOBALROOOTS1** is an international agricultural export & trade web application showcasing premium Indian spices, chillies, turmeric, moringa, cocoa, and raw commodities to buyers across Europe, the Middle East, Americas, and Asia-Pacific.

---

## 🌟 Key Features

- **3D Interactive Trade Globe**: Real-time canvas globe visualizing export routes from India to major global ports.
- **Product Catalog & Sourcing Modal**: Interactive modal showcase detailing ASTA color specs, packaging, and phytosanitary standards.
- **Interactive Logistics Journey**: Seamless animated showcase of inland truck transport, container loading, and ocean freight.
- **Dynamic Light / Dark Theme**: Icon-based dark and light mode toggle.
- **Responsive Architecture**: Built for desktop, tablet, and mobile browsers.

---

## 🛠️ Technology Stack

- **Framework**: [React 18](https://react.dev/) + [Vite 5](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Modern Vanilla CSS + Glassmorphism + Dynamic Design Tokens
- **3D Graphics**: Custom HTML5 Canvas 3D Rendering (Zero heavy 3D library dependencies)

## 🚀 Quick Start Guide

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18 or higher recommended).

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run locally in development mode
```bash
npm run dev
```
Open `http://localhost:3000` in your browser to view the live app.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist` directory.

---

## 🌐 Deploying Live to GitHub Pages

This repository is pre-configured with relative base paths (`base: './'`), `.nojekyll`, and an automated GitHub Actions Workflow (`.github/workflows/deploy.yml`).

### Steps for Deployment:
1. Push this repository to GitHub.
2. Go to Repository **Settings** ➔ **Pages**.
3. Under **Source**, select **GitHub Actions**.
4. Your site will automatically build and publish live at `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`!
